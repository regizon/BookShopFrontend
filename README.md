# BookShop Frontend
<img width="969" height="482" alt="image" src="https://github.com/user-attachments/assets/f1ff226c-54c5-49e4-8dc5-3e455f3d0df0" />

Frontend for the BookStore e-commerce platform. Built with React + TS, connects to
the BookShop API(https://github.com/artem-radostiev/BookShop).

## Tech Stack
- React + TypeScript
- Styling: Default CSS
- Build: Vite

## Getting Started

### Prerequisites
- Node.js >= 11.12

### Installation
​1. Clone this repository.
2. Install requirements.

### Running locally
npm run dev

App runs at http://localhost:5173

## Available Scripts
- npm run dev — dev server
- npm run build — production build
- npm run test — run tests
- npm run lint — lint code
